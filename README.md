# 1 Rep Max Calculator 

This website was built with drafter and estimates a lifter's one rep max and also tracks their progress.  

Here is the link to the deployed website: https://verick-star.github.io/max_rep_estimation/

Here is the link to the walkthrough video: https://drive.google.com/file/d/1wqt66LY7I0mFPykklP5zXbfN7AIDr2r4/view?usp=sharing

# Website Features 
Go to Calculator: User will enter weight lifted and reps done to calculate the estimated 1 rep max.
View History: Review previous lifts for the three different types on exercise
Formula Info: Learn about how the formula works and what actually goes into it.
Best Lift and Leaderboard: View top lifts and were all of your lifts rank amongst one another.
About:  Brief description on what the website does and it's purpose
